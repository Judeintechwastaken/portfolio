# Gym Registration & Subscription Tracker

An automated workflow handling gym member registration, subscription tracking, 
payment collection, and renewal reminders.

## What it does
- Member registration via form
- Subscription tracking and status monitoring
- Payment collection via Paystack
- Automated renewal reminders (3 days before expiry)
- Automated welcome and expiration notification messages
- Payment receipts

## Tools used
- n8n (workflow automation)
- Paystack (payments)
- Email/WhatsApp (notifications)
